# Choir Practice — vendored copy

This is the Choir Practice application itself, not a rebuild of it: 26 files copied
from [xiangthebung/satb-practice](https://github.com/xiangthebung/satb-practice).

It can be vendored because it has no build step and no runtime dependencies — plain
ES modules, hand-written Canvas notation, Web Audio synthesis. `app/demos/choir-practice/demo.tsx`
mounts it in an iframe once the section is scrolled to, with
`allow="autoplay; microphone"` so playback can resume and the pitch guidance can ask
for a microphone.

## What was left out

The tests, the Playwright suite, `tools/`, and the packaging files. The full list is
in the source repository's `.assetsignore`, which exists for the same reason:
`wrangler.jsonc` serves that project straight from its repository root, so anything
sitting there is a deploy candidate.

## Samples

| file | composer | status |
| --- | --- | --- |
| `Draw On, Sweet Night.musicxml` | John Wilbye (1574–1638) | public domain |
| `Quick! We have but a second.musicxml` | C. V. Stanford (1852–1924) | public domain |
| `Warm-up in four parts.musicxml` | generated | written for the repository |

A fourth sample used to sit here, a setting of *Smávinir fagrir*. Its own
`credit-words` name the composer as **Jón Nordal, born 1926**, so the music is
comfortably inside copyright and could not ship on a public page. It was removed
from both projects. The generated warm-up replaced it deliberately rather than
incidentally: two of the test suites depended on having a third sample, and one
browser test needs a score where two voices share a staff, so the generator
reproduces that shape.

## Keeping it current

Re-copy after changing the source project; nothing here is generated by this site's
build. The one thing to watch is that the source's `index.html` links its own
stylesheet and modules with relative paths, which is what lets it work unchanged
from a subdirectory.
